Árbol a fotografiar

Cómo se usa

  1. 1Elige una cara del árbol y toma la foto a 1,5–2 m, con el árbol llenando el encuadre.
  2. 2Toca cada fruto para marcarlo. Toca una caja para borrarla. Ajusta su tamaño con el control deslizante.
  3. 3Guarda. Cada foto queda como parte de tu dataset, con las cajas listas para entrenar un modelo YOLO.

Con un modelo cargado (pestaña Modelo) la app propone las cajas y tú corriges. Sin modelo, el asistente de color ayuda a pre-etiquetar fruta ya coloreada.
